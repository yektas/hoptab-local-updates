# HopTab Local updates

This repository distributes signed, notarized HopTab Local macOS application packages and its Sparkle update feed. Source code is maintained in a separate private repository.

Install the ZIP from the latest release, unzip it, and move HopTab.app to /Applications. Future releases can be installed from **Check for Updates…** in the app or automatically through its update settings.

HopTab Local is derived from [HopTab](https://github.com/royalbhati/HopTab), copyright (c) 2025 HopTab Contributors, under the MIT license. See LICENSE. Third-party notices are bundled inside the app's frameworks.

The initial feed contains no updates; application packages will appear after release signing is configured.
