# HopTab Local updates

This repository distributes Developer ID signed HopTab Local macOS application packages and its Sparkle update feed. Source code is maintained in a separate private repository.

Install the ZIP from the latest release, unzip it, and move HopTab.app to /Applications. Future releases can be installed from **Check for Updates…** in the app or automatically through its update settings.

HopTab Local is derived from [HopTab](https://github.com/royalbhati/HopTab), copyright (c) 2025 HopTab Contributors, under the MIT license. See LICENSE. Third-party notices are bundled in the app’s Resources/THIRD-PARTY-NOTICES.txt.

Releases are Developer ID signed but are not notarized. The first launch may require approval in System Settings → Privacy & Security. Updates are also verified using Sparkle’s EdDSA signature.
